# Interactive Developer Portfolio 💻🤖

A premium, state-of-the-art developer portfolio showcasing advanced full-stack engineering capabilities alongside specialized expertise in Applied AI, Retrieval-Augmented Generation (RAG), and Agentic AI workflows.

---

## 🛠️ Built With

### Frontend & Aesthetics
*   **React 19 & Next.js** (App Router Architecture)
*   **WebGL Fluid Simulation** — Interactive background physics simulation custom-tuned for color-rich, low-glow fluid trails on mouse hover, clicks, and touches.
*   **Vanilla CSS (Glassmorphism)** — Premium frosted glass components, responsive grid systems, and subtle hover animations with custom shadow glows.

### Backend & Database
*   **Neon Serverless Database** — Relational database connection using postgres integrations.
*   **Next.js API Routes** — Secure endpoints for pulling dynamically updated portfolio data (skills, projects, credentials, resume cv links).

### Administration Portal
*   **Secure Admin Dashboard** — An integrated admin workspace to dynamically create, edit, or delete projects, upload certificate credentials, edit contact configs, and add skill badges.

## 🎬 Getting Started

### Prerequisites
Make sure you have Node.js (version 18+ recommended) installed.

### Setup
1.  Clone the repository.
2.  Create a `.env.local` file in the root directory and add your Neon Database connection URL:
    ```env
    DATABASE_URL="your-neon-database-connection-string"
    ```
3.  Install dependencies:
    ```bash
    npm install
    ```

### Development Server
Run the local dev server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to view your portfolio.

### Production Build
Verify compilation and compile optimized assets:
```bash
npm run build
```
